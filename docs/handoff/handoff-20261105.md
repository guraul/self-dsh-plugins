### 本轮抓到的真 bug（症状 / 根因 / 修法 / 教训）

1. **`url.txt` 旧令牌仍有效 → 误判「已就绪」**（#293）
   症状：点升级后进度页显示完成，但打开的地址 401。
   根因：`url.txt` 里的旧 URL 在重启瞬间**仍然能 303**，只判「能不能连」不判「是不是新的」。
   修法：进度服务在启动时记 `baseline`，`done` 要求 `live && candidate !== baseline`。
   教训：**「能连上」不等于「已是新的」**，任何就绪判定都要有「与点击时刻对比」的基线。

2. **我自己三次引入「占位不复位」**（#307 / #313 / #318 各一次）
   症状：某次失败后，该端点永久 409，只能重启宿主。
   根因：加了 `xxxRun = true` 守卫，但漏了某条 early-return / catch 路径没置回。
   修法：**整个 POST 体包 `try { … } finally { xxxRun = false }`**。
   教训：加状态守卫时，先把**所有出口**列出来再写。

3. **`gh pr create` 不带 `--head` 会拿用户当前分支开 PR**（#318）
   症状：功能永远失败；更糟的是会把用户未审核的分支开成 PR。
   修法：显式 `--base main --head <branch>`，并让 `gh` 在临时 worktree 里跑（`defaultRunGh` 原先**忽略 cwd**，本轮补上）。
   教训：**调外部 CLI 时，cwd 与「从哪猜参数」必须显式指定**。

4. **CRLF 修错两次**（#313 / #316）
   症状：`\r\r\n`（双 CR），比原来的 LF 混用更糟。
   根因：`text.split('\n')` 会把 `\r` 留在行尾，再按 `\r\n` join 就多一个 CR。
   修法：用 `split(/\r?\n/)`；或干脆不写那个函数（无调用方的代码别先落地）。
   教训：**改行尾相关代码必须先有 CRLF 用例**，否则测试全绿也说明不了问题。

## §6 已知陷阱与教训

1. **模块级导出的函数必须定义在模块作用域**
   症状：`ReferenceError: xxx is not defined` 导致整个客户端加载失败、所有用例红。
   解法：定义在工厂函数体顶层（与 `phaseText` 同级），别嵌在 `renderSettings` 里再往外 `exports`。

2. **`printf` 与 `python3 -c "…"` 里的反引号 / `%` 会吃掉内容**
   症状：我这轮写 CHANGELOG 时，反引号被 shell 当命令替换执行，写进去的段落变成空壳，还产生了重复小节。
   解法：**多行文本一律用 `python3 - <<'PY'` heredoc 或 `--body-file`**，绝不用 `python3 -c "…"` 拼内容。

3. **合并后 `fetch origin` 失败**（今天出现 3 次）
   症状：`merge-pr.sh` 停在 fetch，`main` 没快进。
   解法：远端已改 SSH（`git@github.com:guraul/self-dsh-plugins.git`），`git fetch origin main && git merge --ff-only FETCH_HEAD` 补上即可。

4. **400 行高风险闸门**
   症状：`E_POLICY: 变更 441 行，超过 400 行上限`。
   解法：先把测试与文档算进预算；真超了就得让**用户当场同意**，然后 `merge-pr.sh --no-review --reason="…"` 并在 PR 上留言留痕。

5. **codebuddy reviewer 读不到 `/tmp`**
   解法：任务书里给**仓库内相对路径**（`.tmp/review/<PR>/prompt.md`），别给绝对 `/tmp/...`。

6. **审核判定格式必须逐字**
   reviewer 有时写成「结论: 通过」。`record` 只认 `XXXX VERDICT: APPROVE|REJECT|ESCALATE SHA: <sha>`。写错就重发一次追问，或按同样内容规范化后再 record。

7. **`gh` 报「令牌无效」九成是沙盒拦了钥匙串**
   解法：只读判别 `security find-generic-password -s "gh:github.com" >/dev/null 2>&1; echo $?` → `44` = 钥匙串读不到（沙盒问题）。**别 `gh auth login`**。

8. **`git worktree` 在 linked worktree 里按 cwd 推容器会嵌套**
   解法：容器路径以主工作区为基准（`git rev-parse --git-common-dir` 的父目录）。

**本仓代码红线**：只允许根目录一份 `AGENTS.md`；只用 pnpm；所有改动走 issue → worktree → PR → 审核 → `merge-pr.sh`；**禁止直推 main**。

**上一棒踩过的错**（别重蹈）：① 声称「已删干净」实际留了死代码；② 测试只覆盖 happy path 就宣布修好；③ 用 `git add -A <目录>` 把自动生成的 lockfile 扫进 PR。
