### 2.6 关键契约与术语（自包含摘要，细节见 REQ-001 §7–§8）

**三种候选接入形态**

| 形态 | 承载方式 | 能读仓库 | 模型可选 | 外部依赖 |
|---|---|---|---|---|
| A 原生 | DSH 插件注册的子代理 provider | 是 | 是（DSH 已配置的模型） | 无 |
| B 委派 | opencode / codebuddy（经 ACP 桥） | 是 | 是（调用时显式指定） | 远端 CLI + 鉴权 |
| C 伪模型 | 网页清言（经浏览器扩展桥接） | 否 | 否 | 浏览器 + 扩展 + 登录态 |

**输入 `ReviewRequest` 必填**：`pr`、`head_sha`、`issue`、`files`、`diff`。
`diff` 属于不可信数据，必须围栏包裹并声明为数据。

**输出 `ReviewResult` 必填字段**

| 字段 | 含义 |
|---|---|
| `verdict` | `APPROVE` / `REJECT` / `ESCALATE` 三值之一 |
| `head_sha` | 必须回显请求中的提交；合并前重读 PR head 比对 |
| `findings` | 问题清单 `[{severity, file, line, message}]` |
| `evidence` | 支撑判定的证据（具体文件:行） |
| `form` / `model` | 实际使用的形态与模型标识 |
| `durationMs` / `traceId` | 耗时与审计关联 id |

**三条不变式**（违反即判 `ESCALATE`）

1. 判定只对 `head_sha` 有效，提交变了判定作废；
2. 判定行必须带一次性随机标记（每轮生成，不出现在 diff 中），防止伪造；
3. 没有判定行 / 判定多义 / 超时 / 形态不可用 → 一律 `ESCALATE`，绝不视为通过。

## §6 已知陷阱与教训

每条都带解法，只写现象不写解法的条目不予收录。

| 陷阱 | 解法 |
|---|---|
| 重启 dsh web 会**终止当前会话** | 用 `.dsh-web/restart-once.sh`（延迟 30s 执行，先让回复发出去）。**实测教训**：该脚本作为宿主子进程运行，宿主被 kickstart 杀死时脚本一起被杀，自检日志只写了前两行——但 kickstart 已生效。若需要完整自检，把脚本用 `setsid` 脱离宿主进程组 |
| macOS 自带 bash 3.2 | 不用关联数组、`mapfile`、`${var^^}`、`declare -A`；默认值用 `if [[ -z "${VAR}" ]]` 判断，不写 `${VAR:-默认}` |
| macOS 没有 `timeout` 命令 | 用 `curl --max-time` 或后台任务控时 |
| `gh pr checks --fail-fast` 在 gh 2.42.1 下报参数非法并 exit 1 | 已被 `merge-pr.sh` 修掉（issue #5）：改为取原文 + 退出码，以输出文本判定；保留 `--check-only` 与 `--checks-file` 两个开关 |
| `gh pr edit` 因 Projects (classic) 弃用返回 GraphQL 错 | 改用 REST；多行 body 一律 `--body-file` |
| `gh` 在受限沙盒下报「令牌无效」 | 是钥匙串被沙盒拦住，不是令牌过期。用完整权限运行，**不要**重新 `gh auth login` |
| DSH 插件 peer 版本不覆盖当前宿主 | profile 会**静默跳过**该 bundle（表现是「插件莫名其妙没加载」，不是崩溃）。版本豁免流程见 `docs/plugins/dsh-plugin-product-subagents.md` |
| 子代理委派不指定模型会落到会话默认模型 | 每次显式传 `provider/model` 全名；`--agent <name>` 不会应用该角色的 model |
| 仓库根**没有** `scripts/lint.js` | 只有 `dsh-awake/scripts/lint.js`。根 `AGENTS.md` 里「门禁 = `node --test` + `node scripts/lint.js`」要按**插件内**理解，别在根目录找 |
| `.gitignore` 是白名单 | 新目录（如 `docs/requirements/`）要先确认被放行，否则 CI 检出后看不到。`docs/` 已放行，当前无问题 |
| 不要复活「清言逆向接口 provider」方案 | 已否决（账号风控 + 违反服务条款），源码已删除 |

**根 `AGENTS.md` 哪些适用于你**：§「强制规定」全部适用；「已知坑」全部适用。
`~/.dsh/AGENTS.md` 中 §3（依赖用 pnpm）、§7（交付流程）、§8（控制面/执行面分工）、§12（宿主安全）适用；§9（子代理模型档位）只在你要委派子代理时适用。
