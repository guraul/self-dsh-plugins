## 约定

- 每份需求都必须包含：范围（含明确排除项）、角色与职责、接口约定、异常与超时、可测的验收标准；
- 验收标准无法验证的条目不得进入验收；
- 高风险变更（流程、CI、依赖）在需求层面就标注为「必须人工」。
